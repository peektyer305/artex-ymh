# DBの変更

SQLは0001_baseline.sqlから番号順に適用します。適用済みのSQLは変更せず、0002_内容.sqlのような新しいファイルを追加してください。既存DBでは最初の起動時に従来の冪等な定義を一度適用し、チェックサムを記録します。以降の起動では同じSQLを繰り返し実行しません。

DDLと適用記録は同じトランザクションに保存します。既存のadvisory lockを維持し、デッドロック時はトランザクション全体を再試行します。DBが新しいバージョンの場合や適用済みSQLの変更がある場合は起動を停止します。

組み込みデータは別のバージョンで管理します。新しい初期データ更新を配布するときは、db.OpenのapplySeedVersionの番号を増やし、再実行可能な更新を追加してください。ユーザーの編集を保持する既存のseed処理は維持しています。

適用前のDBバックアップを取得してください。ソースコードの復元だけでは、適用済みのDBマイグレーションは取り消されません。
