# PostgreSQLを使うGoテスト

テスト用のDBを用意し、`ARTEX_PG_DSN`に接続先を指定します。指定したユーザーには、そのDBにスキーマを作成する権限が必要です。

```powershell
$env:ARTEX_PG_DSN = "postgres://artex:artex@localhost:5432/artex_test?sslmode=disable"
go test -count=1 ./...
go vet ./...
```

各パッケージの`TestMain`は専用の空のスキーマを作ります。接続先の`search_path`をそのスキーマだけに設定し、既存のテーブルや別のパッケージのテストデータを参照させません。終了時には作成したスキーマを削除します。

DB名は変更しません。指定したDBは事前に作成してください。途中でプロセスを強制終了した場合は、`artex_test_`で始まるスキーマが残ることがあります。

DBの設定がない場合、DBを必要とするテストはスキップされます。DBを含めて確認する場合は、上の環境変数を設定してください。PHP CLIや外部LLMが必要なテストは、それぞれの実行条件がそろわなければスキップされます。

DBテストで行数や固定の識別子を検証する場合は、パッケージ内でもテスト同士が影響しないようにします。`db`パッケージでは`isolatedTestDB(t)`でテストごとのスキーマを作れます。

`t.Cleanup`でデータを削除する場合は、DB接続を閉じる処理も`t.Cleanup`に登録します。先に登録した処理ほど後で実行されるため、接続を閉じる処理を最初に登録してください。`defer db.Close()`で先に閉じると、後から実行されるデータ削除が失敗します。
