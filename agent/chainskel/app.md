# chains-app L3 意思決定チェーン(場面→判定基準→方向転換;chains コーパスから蒸留,完全な Q&A は skills/chains-app/refs/ を参照)
- 場面:未知の APK を入手し API/鍵を抽出|判定基準:まず unzip でディレクトリを走査。Manifest で権限/exported を、lib/ で特徴的な so を見る。5 分で「純 Java」か「コアが native/パッカー」かをトリアージ|方向転換:主 dex に業務クラスがなく、application:name がプロテクト SDK を指していればプロテクトとして扱う
- 場面:jadx でクラス名が全て一文字|判定基準:難読化 ≠ プロテクト。http/api/パッケージ名を検索し、業務文字列が見つかれば難読化、dex にパッカー SDK しか残っていなければプロテクト|方向転換:難読化なら文字列駆動の精読へ。プロテクトならまず assets/meta-data の平文を搾り取ってからアンパックを決める
- 場面:平文の鍵を素早くすくい取る|判定基準:secret/appkey/ak/sk/BEGIN、クラウド接頭辞 AKIA/LTAI/AKID、高エントロピー文字列を検索。60% は低い枝の果実。assets が最も漏れやすい|方向転換:生存確認できるかでソート(CLI で最小呼び出し)。失効した key は情報として同種を横展開で探す
- 場面:プロキシ設定済みなのに App にトラフィックがない|判定基準:ハンドシェイク直後に close_notify = Pinning(logcat に SSLHandshakeException の鉄証)。リクエストが完全に無い = システムプロキシ非経由。ハンドシェイクがプロキシに届かない = 非 HTTP|方向転換:それぞれ pin 回避、tun 透明プロキシで強制キャプチャ、tcpdump でポート確認。2~4 時間平文が出なければサーバー側を攻める
- 場面:SSL Pinning を確認|判定基準:汎用 unpinning スクリプト/objection が 60%~90% を一掃。無効なら四層を調べる:TrustManager/CertificatePinner/Conscrypt/native。全て該当しない = pin が BoringSSL にある|方向転換:native hook で SSL_get_verify_result を 0 に返す。mTLS なら .p12 証明書を探し + KeyStore.load を hook してパスワードを取得。全て塞がれたら hook を平文に変更
- 場面:純粋な静的解析で API リストが欲しい|判定基準:Retrofit で @GET/@POST/@Path/@Body アノテーションを検索し、パス+base_url で完全な URL を組み立てる。パケットキャプチャより網羅的|方向転換:アノテーションが R8 で削除されたら /api/ 定数と OkHttp の Request.Builder 構築箇所の検索に退く
- 場面:ロジックが native so にある|判定基準:hook で結果を得る ≪ アルゴリズムを逆にする。まずブラックボックスで native メソッドを hook し引数と返り値を見る。多くはそれで十分。OLLVM を静的解析で無理に追わない|方向転換:オフライン再現が必須の場合のみ IDA に。JNI エクスポート名/文字列/暗号 API のアンカーから切り込む。遮られたら unidbg へ
- 場面:frida を使う|判定基準:server と host のバージョン・アーキテクチャを厳密に一致させる。frida-ps -U でプロセスを列挙できて初めて疎通。attach 直後に落ちる = 反 frida(27042 走査 / maps 内の gum / TracerPid)|方向転換:ポート変更 + spawn で先に注入 + gadget で特徴を除去。それでも落ちるなら LSPosed か unidbg へ
- 場面:静的解析でアルゴリズムが見えない|判定基準:広域 hook で口を絞る。Cipher.init で key/iv、doFinal で平文・暗号文ペア、Mac/MessageDigest で署名入力を取る。実行時にアルゴリズムが自ら名乗る|方向転換:文字列暗号化は hook で統一 decrypt 出口を一括復元。出口がなければ String コンストラクタなど下層に沈む
- 場面:プロテクトを確認|判定基準:点的に鍵を取るなら hook で十分、面的にコードを精査する場合のみアンパック。1 時間のタイムボックスを設ける。全体型 vs 抽出型を分岐:メソッド insns 長が 0、code_off が大量に同一 = 抽出型|方向転換:全体型は dex\n035 マジックナンバーで dump。抽出型は fart の能動的呼び出しで埋め戻し。VMP は復元を諦め純ブラックボックス
- 場面:ローカルストレージの鍵を掘る|判定基準:平文の可能性順に辿る:shared_prefs(token は平文が多い)→databases(.tables で user/token テーブルを探す)→files→/sdcard(root 不要)|方向転換:暗号化ならアルゴリズムを逆にしない。SQLCipher は openDatabase を hook して password を取る。key が TEE にあり取り出せないなら doFinal を hook して App に代行復号させる。root なしなら adb backup
- 場面:対象が WeChat ミニアプリ|判定基準:root デバイスで一度開いて暗号化された wxapkg を取り、ほぼ平文の JS を解く。直接 request ドメイン(全バックエンドを逆引き)、appid/クラウド環境 ID、フロントエンドの認可検証へ|方向転換:クラウド開発ならクラウドデータベース直結を攻める(ルールが緩すぎてテーブル全体の読み書きを権限外アクセスできることが多い)。実機が制限されているなら開発者ツールか直接バックエンドを打つ
- 場面:body が暗号文|判定基準:長さが 16 の倍数 = AES/SM4。0x1F8B=gzip / 0x789C=zlib はただの圧縮。特徴定数で即判定(MD5 0x67452301、SM4 CK/FK)|方向転換:既知平文から暗号化箇所を逆引きするか、JSON 入口を hook して逆引き。アルゴリズムが複雑なら逆にせず、App を暗号化・復号のオラクルにする
- 場面:パラメータを変えると署名エラー|判定基準:MessageDigest.update/Mac.doFinal を hook し「どの digest の返り値が sign と等しいか」を遡って原文を得る。常に食い違うなら四点を調べる:タイムスタンプ精度、nonce、フィールド並び順、隠しフィールド|方向転換:アルゴリズムを逆にせず App を署名オラクルにする。ts+nonce をリアルタイム再署名。旧パケットは弾けてもリアルタイム署名は弾けない
- 場面:protobuf/独自バイナリ|判定基準:先頭バイトは tag<<3|wiretype(0x08/0x10/0x1A)。decode_raw で盲目的に骨格を解く。schema は GeneratedMessage クラス内。独自プロトコルは長さプレフィックス + magic でフレームを定める|方向転換:生成クラスがなければ hook でシリアライズ両端から「オブジェクト↔バイト」対応を取り、コーデック RPC として使う
